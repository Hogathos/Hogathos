- 🛠️ Path: Python → networking / sysadmin → DevOps → AgentOps
- 👁️ Building Iris: Watch, Verify, Steer, Meter, local-first, metadata only, human in loop
- 🔍 Iris checks what an agent said it did, against what actually happened, by independent read-back. Correct / Incorrect / Unverified. No score. No LLM-as-judge.

### Iris

| | |
|---|---|
| **What** | A local proxy that watches agent traffic |
| **Where** | Port 8888, on loopback only |
| **Human** | Pause one run, redirect one run, or stop all runs |
| **Journal** | Journals first, then cuts |
| **Retry** | A run cannot retry until a human checks it again |
| **Rule** | It stops unless a human verifies everything is fine |
| **Tests** | 84, CI green |
| **License** | AGPLv3 |
| **Status** | Observe built, Control and Confirm partly built, Measure next, app mode next, second user next |
